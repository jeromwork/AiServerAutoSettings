# Проверка установки чатов — 3 ноября 2026

## Установлено на выбранном сервере

- Happier stable 0.2.17: официальный установщик выполнил проверку контрольной суммы и подписи.
- Codex CLI 0.166.0 и Claude Code 2.1.311: доступны серверному пользователю.
- Пользовательская служба Happier включена, активна и ждёт подключения аккаунта.
  Включён запуск пользовательских служб без открытого сеанса Linux.
- Повторная установка использовала существующие компоненты; процесс службы не перезапускался.
- Веб-интерфейс Happier открыт; ярлык браузера создан на рабочем столе Windows.

## Что проверено

- Полный путь установки обоих агентов через функцию установщика завершился успешно на сервере.
- Настоящая проверка авторизации через новый Windows-помощник дошла до Happier на сервере:
  получен структурированный ответ `not_authenticated`, а не ошибка транспорта или пароля SSH.
- В Windows PowerShell 5.1 прошли проверки выбора агентов, повторного открытия без установки,
  отмены и обработки неудачной установки. Для всех людей используется один пункт открытия чатов.
- Проверено настоящее окно Windows Forms с тестовым SSH: нет входа, вход выполнен,
  ссылка подтверждения, обрыв SSH и зависание. При зависании управление возвращается за 10 секунд.
- Одноразовая ссылка входа не попадает в журнал; проверены допустимые адреса и имена пользователей.
- Проверка быстрого входа установщика прошла. Синтаксис создаваемых shell-команд проверен.
- Переносимый комплект собирается только по публичному манифесту; перед упаковкой запускается
  проверка состава, синтаксиса PowerShell, личных путей и секретов.

## Требуется действие владельца

Вход в Happier и провайдеров Codex/Claude выполняет владелец. На момент проверки сервер
ещё не привязан к аккаунту Happier; Codex также ожидает входа. Автоматический вход от имени
владельца не выполнялся. После входа нужно проверить первый ответ, поток событий, голос
и продолжение чата с другого устройства. Эти проверки пока не считаются пройденными.

Отдельные профили людей убраны: на разных устройствах используется общий аккаунт Happier,
а проекты и чаты выбираются в браузере. Одновременная работа нескольких людей пока не проверена.
Перезапуск всего VPS ради проверки автозапуска не выполнялся.

Порядок первого подключения и ограничения описаны в [инструкции](REMOTE-CHAT.md).
