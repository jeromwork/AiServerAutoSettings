# Продолжение на другом компьютере

Снимок исходников: 31 октября 2026. Репозиторий содержит переносной код, а не состояние прежнего сервера или компьютера.

## Подготовлено

- Единый запуск через `01-setup-ssh.cmd`, проверка Windows PowerShell 5.1 и OpenSSH, первичный вход по паролю, локальные профили и SSH-ключи.
- Выбор Codex/Claude, браузер/рабочий стол сервера, RDP-звук, добровольная установка Amnezia.
- WinForms-выбор проектов, обычные папки и Git worktrees; отдельные рабочие копии; мост Windows-команд и передача первого сообщения агенту.
- Runtime-скрипты и локальные fixture-тесты, без скачанных установщиков, личных профилей, идентификаторов устройств и адреса прежнего VPS.

## Точный незавершённый этап

Полная проверка синхронизации через SSH на реальном VPS **не завершена**: предыдущее продолжение остановилось на доступности SSH. Результаты локальных fixture-тестов не заменяют такую проверку. Здесь не заявлены успешные личный вход, полный рабочий диалог модели, работа звука или совместимость VPN на новом сервере.

На другом ПК добавьте свой VPS заново, проверьте SSH в меню установщика, выберите тестовый проект без личных данных и пройдите цепочку: выбор проекта → первоначальная передача → свежая проверка копий → серверное изменение файла → появление в отдельной Windows-копии. Затем проверьте удаление тестового файла, отключение/восстановление соединения и отказ запуска команд при несвежей копии или конфликте. Оригинальная папка должна остаться неизменной. Лишь после этого проверяйте вход в Codex/Claude и передачу задачи агенту.

Не переносите прежние ключи, профили, аккаунтные файлы и настройки VPN. Не запускайте старые acceptance-сессии с жёстко заданными локальными путями: они намеренно не включены. Для работы достаточно README и меню установщика.

## Проверки этой поставки

Фактические результаты упаковки записаны в [PACKAGE-CHECKS.md](PACKAGE-CHECKS.md). Дополнительные `test-*` предназначены разработчику: часть требует Python, Linux/bash либо самостоятельно скачанный официальный архив Syncthing. Для обычного запуска установщика эти тестовые зависимости не нужны.
