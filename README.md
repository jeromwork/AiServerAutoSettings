# Windows → VPS: Codex и Claude

Переносной комплект установщика для Windows 10/11 и Ubuntu VPS. Это текущая рабочая версия для продолжения настройки, а не подтверждённый production-релиз. Незавершённые проверки описаны в [CONTINUE.md](CONTINUE.md).

## Запуск на другом компьютере

1. В GitHub выберите ветку `codex/portable-installer-package`, нажмите **Code → Download ZIP**, распакуйте **всю** папку в обычную доступную для записи папку. Либо выполните `git clone --branch codex/portable-installer-package https://github.com/jeromwork/AiServerAutoSettings.git`.
2. Дважды нажмите **01-setup-ssh.cmd**. Не запускайте отдельные серверные скрипты вручную.
3. Добавьте свой сервер: адрес, имя подключения и SSH-пользователя. Первое подключение поддерживает `root` и пароль: пароль вводится в отдельном окне OpenSSH и не записывается в комплект. Проверьте отпечаток сервера. Для дальнейших подключений установщик подготовит ключ и профиль локально на этом компьютере.
4. Выберите **Codex**, **Claude** или оба приложения. Выберите работу на сервере или с папками Windows. В окне выбора отметьте нужные проекты: обычные папки, Git-репозитории и Git worktrees поддерживаются отдельно.
5. Откройте рабочий стол сервера через меню и войдите в выбранное приложение самостоятельно. Для CLI Codex используйте `codex login --device-auth`: ссылку и код открывайте в Chrome **на сервере**. Учётные записи и история с прежнего компьютера не переносятся.
6. Откройте на рабочем столе сервера ярлык **«Начать настройку проекта»**, выберите показанную папку в приложении и отправьте подготовленное первое сообщение. Для Claude используйте вкладку **Code**. Для Codex после подключения при необходимости откройте **Settings → MCP → Restart**.

Оставляйте установщик открытым во время работы: он держит SSH-туннели, синхронизацию и мост команд. Отключайтесь через его меню. Исходная папка проекта сохраняется; сервер работает с отдельной копией, изменения возвращаются в отдельную рабочую копию Windows. Перед выдачей доступа к командам установщик проверяет состояние копий. Разрешение команд даётся отдельно; команды имеют права текущего пользователя Windows.

## Что нужно

- Windows PowerShell **5.1**, .NET Framework/Windows Forms, клиент OpenSSH **8.6+** (`ssh.exe`, `ssh-keygen.exe`), штатный клиент удалённого рабочего стола и интернет.
- Ubuntu VPS с доступом root или правами для установки системных компонентов. Это установщик: он меняет сервер и ставит выбранные приложения.
- Python, Codex и Claude **на Windows для обычного запуска не нужны**. Серверные Python-скрипты исполняются на Ubuntu. Python на Windows требуется только разработчику для дополнительных тестов.
- Обычный запуск не требует «Запуск от администратора». UAC может понадобиться при добавлении компонента OpenSSH в Windows или при отдельной установке VPN.

При отсутствии Git установщик загружает официальный portable MinGit и проверяет закреплённую SHA256. Syncthing скачивается с официального GitHub с закреплённой SHA256. Большие установщики, архивы и кэши в репозиторий не входят. Загрузка Amnezia выполняется отдельно с официального GitHub, проверяется подпись установщика; VPN включается только по выбору пользователя. Существующий корпоративный VPN и маршруты не считаются проверенными совместно с Amnezia.

## Дополнительные возможности

Серверный браузер, рабочий стол, звук через RDP, безопасный выбор папок, Git worktrees, синхронизация обычных папок и передача контекста агенту включены в комплект. Готовность этих компонентов кода и локальные проверки не означают успешной проверки на новом VPS. Личные профили, ключи, токены, адрес прежнего сервера и аккаунтные файлы переносить не нужно: добавьте сервер заново.
