# Задача: удобное главное окно RemoteAgents

Владелец, 15.11.2026: «сейчас очень неудобное главное окно». Ветку отводить от `main`, готовое вливать в `main`
с тестами (`app/launcher/tests/run.sh`), EXE выдавать только GitHub-релизом.

## Что сейчас плохо
`app/launcher/ConfigWindow.Main.cs` (`BuildMain`):
- первая вкладка — текстовый редактор конфига JSON;
- вкладка «Подробно» — встроенный мастер;
- вкладка «Сервис» — пачка статусов, выпадающий список путей, кнопки, ключ Happier;
- над вкладками 5 строк статуса.

Человек без подготовки не понимает, где что. Так сделаны только приложения для технарей (v2rayN, NekoBox). Happ, Hiddify,
Cloudflare WARP, Яндекс Диск, Dropbox и OneDrive показывают на первом экране одно главное действие и одну понятную фразу
состояния, а остальное прячут за шестерёнкой.

## Что сделать

### Трей — НЕ МЕНЯТЬ
- **Левый клик по значку в трее открывает сайт Happier, как сейчас** (`TrayMenuModel.LeftClickAction`). Это решение владельца.
- Главное окно открывается из меню трея («Открыть» → «Настройки» / окно программы), как сейчас.
- Пункты меню трея не убирать без вопроса владельцу.

### Первый экран — карточки
Окно небольшое (примерно 420×600 при 100 % DPI), шрифт Segoe UI, светлые плоские карточки с отступами, без вкладок.

```
┌───────────────────────────────────┐
│ RemoteAgents                   ⚙  │
├───────────────────────────────────┤
│ ⚠ Нет связи с сервером.           │  ← полоса только при проблеме
│   Пробуем запасной путь  [Повтор] │
├───────────────────────────────────┤
│ VPN              [██ ВКЛ ]        │  ← большой переключатель
│ Защита включена                   │
│ через «Основной», 42 мс  Авто ▾   │  ← выбор пути (бывший pathChoice)
├───────────────────────────────────┤
│ Диск   ✔ Всё синхронизировано     │
│ 12 папок · 3 только на сервере    │
│ [Открыть Диск]                    │
├───────────────────────────────────┤
│ Happier  ✔ аккаунт подключён      │
│ [Открыть Happier] [Копировать ключ]│
├───────────────────────────────────┤
│ Помощник может управлять          │
│ компьютером: подключён            │  ← состояние моста
└───────────────────────────────────┘
```

1. **Карточка VPN.**
   - Большой переключатель вкл/выкл (собственный контрол).
   - Крупная фраза состояния и одна серая строка: активный путь и задержка.
   - Ссылка «Авто ▾» для выбора пути.
   - Переключатель вызывает те же действия, что меню трея. Новой логики VPN не добавлять.
   - Во время включения переключатель показывает «Включается…» и заблокирован.
   - Ошибка включения показывается полосой с понятной причиной.
2. **Карточка «Диск».**
   - Одна строка статуса (синхронизировано / идёт синхронизация N / ошибка / нет связи), число папок и «только на сервере».
   - Кнопка «Открыть Диск» открывает папку в Проводнике.
   - «Скачать на компьютер» и «Оставить только на сервере» остаются в меню Проводника.
3. **Карточка Happier.** Аккаунт, «Открыть Happier». «Показать/Копировать ключ» — из нынешнего `BuildHappierAccount`, с тем же
   правилом: ключ не попадает в журналы, скрывается при уходе со страницы.
4. **Строка «Помощник».** Состояние моста (подключён / нет связи с причиной).
5. **Полоса ошибок (как InfoBar).**
   - Одна, сверху, только самая важная проблема.
   - Внутри понятная фраза без технических слов, одна кнопка действия и «Подробнее» (ведёт в «Диагностику»).
   - Если нет и туннеля, и моста, показывается одна полоса, а не две.
   - Цвет совпадает со значком трея: серый — выкл, зелёный — ок, жёлтый — сбои, красный — нет связи.

### ⚙ Настройки — отдельная страница (или окно)
- Разделы-карточки: Сеть и пути, Локальные сети (OpenVPN клиники и т.п.), Диск, Happier, Помощник, О программе.
- Сюда переезжают разделы нынешнего мастера «Подробно» (`SetupWizard` встроенный).
- **«Дополнительно»** — внизу, свёрнуто:
  - **Редактор конфига** — нынешняя первая вкладка, вместе с журналом применения.
  - **Диагностика** — бывший «Сервис»: статусы, пути, технические детали, кнопка «Скопировать отчёт» без секретов.

### Убрать
5 строк статуса над вкладками и сами вкладки. Их информацию передают карточки, полоса ошибок и «Диагностика».

## Как делать
- Остаёмся на WinForms .NET 4.8. Перерисовывать: свои карточки (`Panel` со скруглением), свой переключатель.
- Тёмный заголовок и Mica — через `DwmSetWindowAttribute` (Windows 11 build 22000+ / 22621+). На Windows 10 они просто не
  включаются.
- WPF/ElementHost и WebView2 не брать: долго, тяжелее, единый EXE усложняется.
- Состояния считать в одном месте (модель «здоровья»: VPN, Диск, Happier, мост) из тех же свежих файлов `status/*.json`,
  что трей и подсказка (`StatusView`). Второго источника правды не делать.
- Модель экрана (тексты карточек, какая ошибка главная, цвета) — отдельный класс без WinForms, покрыть тестами в
  `app/launcher/tests` (как `TrayMenuModel`, `WindowModel`).
- DPI 100/150/200 %, длинные русские строки не обрезаются.
- Блокировки сохранить: `WindowModel.CanOpen` / `MutationConflict` (нельзя применять настройки во время другой операции).

## Порядок
1. Перестановка: карточки, настройки, «Дополнительно». Это основная польза.
2. Оформление: цвета, переключатель, заголовок, Mica.
3. Сборка, релиз, проверка на «Компе»:
   - левый клик по трею по-прежнему открывает Happier;
   - VPN включается и выключается с карточки;
   - Диск и Happier показывают верный статус;
   - при обрыве связи появляется одна полоса;
   - редактор конфига работает из «Дополнительно».

## Не делать
- Не менять поведение левого клика трея.
- Не менять логику VPN, Диска и моста — только интерфейс к ним.
- Ничего не удалять из возможностей (редактор, мастер, выбор пути, ключ Happier), только переносить.
