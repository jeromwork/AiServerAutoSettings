# Удаление программы одним действием (решение владельца 16.11.2026)

«Так не делают, чтобы программа была удалена, но осталась куча мусора». Файлы пользователя (папка Disk) остаются,
всё своё программа убирает сама, без ручных шагов и отдельных инструментов. Опись того, что программа создаёт и что
сейчас не убирается, — [UNINSTALL-INVENTORY.md](UNINSTALL-INVENTORY.md) (по коду main 16.11, file:line).

## Сейчас
`RemoteAgents.exe --uninstall` снимает только `Run\RemoteAgents`, останавливает трей, снимает меню/значки Disk v1 и
значок в панели Проводника. Остаются: оба EXE и бандлы, `%LOCALAPPDATA%\RemoteAgents` (конфиг, секреты, ключи, логи),
`%LOCALAPPDATA%\RemoteDisk` (Syncthing с идентичностью и БД, Syncthing Tray), `Run\RemoteAgentsControl` и `Run\RemoteVPN`
(мост и VPN запустятся снова при входе в Windows), задачи планировщика, служебные файлы в папках Disk, следы старых версий,
а на сервере — ключ `ra-config`, устройство Syncthing, регистрация моста. В «Приложениях» Windows программы нет.

## Как должно быть
1. **Где.** «Параметры Windows → Приложения» (запись `HKCU\…\Uninstall\RemoteAgents`, без прав администратора) и
   ⚙ → «Дополнительно» → «Удалить программу». Оба вызывают один и тот же `--uninstall`.
2. **Одно окно.** «Удалить RemoteAgents? Ваши файлы в папке Disk останутся.» Галочка «Отключить компьютер от сервера»
   (включена). Кнопка «Удалить». Больше вопросов нет.
3. **Порядок.**
   1. Остановить всё своё: трей RemoteAgents и RemoteVPN, VPN (штатный откат TUN/маршрутов), канал sing-box, ssh, мост,
      Syncthing и Syncthing Tray — по Job-объекту и по пути исполняемого файла в наших папках.
   2. Сервер (если есть связь и галочка): компьютер сам снимает себя — свой ключ `ra-config:<id>`, устройство Syncthing,
      регистрацию моста/`deviceName`. Нужна серверная команда `remoteagents config forget` (самоотзыв по своему ключу).
      Нет связи — удаление продолжается, в итоге написано, что снять на сервере (`config revoke <id>`).
   3. Реестр: Run `RemoteAgents`, `RemoteVPN`, `RemoteAgentsControl`; все меню `RemoteAgents.Disk.*`; значок Disk
      (CLSID/NameSpace/HideDesktopIcons); задачи `RemoteAgents*`, `RemoteDisk*`; запись Uninstall.
   4. Папки Disk: свои `desktop.ini`/значки/атрибуты, пустые заглушки, `.stfolder`, `.stignore-remoteagents` и строка
      `#include` в `.stignore`. Файлы пользователя и `.stversions` (старые версии файлов) не трогать.
   5. Папки программы: `%LOCALAPPDATA%\RemoteAgents`, `RemoteDisk`, `RemoteAgents-old-backup-*`, свои временные файлы.
      Запущенный EXE себя не удалит — последним шагом короткий скрипт в `%TEMP%` ждёт выхода процесса, удаляет папку и себя.
4. **Проверка и итог.** После удаления программа сама сверяет: процессов, ключей реестра, задач, адаптера и папок нет.
   Итог одной строкой: «Удалено. Оставлено: папка Disk с вашими файлами». Если что-то не снялось — что именно и
   «Повторить» (повтор безопасен).
5. **Старые версии.** Тот же `--uninstall` убирает всё известное от прежних версий (AiServerSync, RemoteDisk_add,
   RemoteAgentsV1_*, задачи RemoteDiskChannel/Folders, VPN-задачи RemoteAgents-TUN-*). После этого `tools/legacy-cleanup`
   удаляется из репозитория.
6. **Переустановка.** Новый EXE после удаления ведёт себя как на новом компьютере: сразу окно «Вставьте конфиг».

## Проверка (до слияния в main)
- Тест «след установки»: снимок до установки (реестр HKCU нужных веток, задачи, `%LOCALAPPDATA%`, папки Disk, Run) →
  установка из конфига → `--uninstall` → снимок; разница должна быть пустой, кроме файлов пользователя.
- Те же сценарии: без связи с сервером; с включённым VPN; с запущенным мостом; повторное удаление.
- Живая приёмка на Windows — только по «да» владельца.

## Связанное (тот же раунд исправлений, 16.11)
- Выдача конфига (`remoteagents config export`) сама кладёт всё нужное для этого сервера: канал, если прямой SSH режется;
  `agent.sudo` по фактическим правам. Флаг `--vpn off` не должен выкидывать канал.
- Подключение компьютера не меняет сервер (16.11 программа сама записала `sshd` лимиты на 109) и не блокирует Связь/Диск/
  Мост из‑за серверных пунктов вроде `agent: blocked`.
- Вставка конфига на видном месте главного окна, а не ⚙ → «Дополнительно» → «Редактор конфига».
